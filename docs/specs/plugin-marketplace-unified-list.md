# 插件市场统一列表规格

## 产品规则

- 插件市场发现页使用一个连续列表，不再提供「公开 / 个人」两个切换标签。
- 列表先展示官方市场目录（Featured 与分类），随后按现有排序规则展示个人来源；个人插件仍按市场分组，不能与官方分类混排。
- 搜索始终跨官方目录和个人来源，显示同一条统一搜索结果流。
- 已安装条、管理已安装入口、插件详情、安装/更新和分组折叠行为保持不变。
- 添加个人市场成功后，新来源直接出现在同一列表中；不再通过切换分段定位。
- 没有个人市场插件时不显示独立的个人空态；官方目录原有的加载和空态仍保留。

## 状态与投影所有者

- `PluginStorePage` 负责搜索词及市场操作；不再持有公开/个人分段选择状态。
- `PluginStoreListView` 从现有插件目录投影官方目录分类与个人市场分组，并按上述固定顺序渲染。
- 插件数据与市场来源仍由现有插件管理 store 管理；本规格不新增缓存、持久化或服务端状态。

## 验收场景

- 页面没有公开/个人切换控件；官方目录和已添加的个人市场插件同时出现在一个列表中。
- 添加个人市场后无需切换标签即可看到该市场分组和插件。
- 搜索可分别命中官方插件与个人来源插件；清空搜索后两个区域都恢复。
- 官方分类排序、精选顺序、个人市场分组/排序及手动折叠均保持现有行为。
- 在桌面与窄屏、浅色与深色主题下，统一列表可浏览，主要操作仍可用。
